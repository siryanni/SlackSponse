# SlackSponse

SlackSponse is a basic Slack bot designed to provide quick utility commands and lighthearted content directly within your workspace channels.

---

## Command Reference

The bot currently supports the following slash commands. Ensure you type them exactly as listed below:

| Command | Description |
| :--- | :--- |
| `/slp-help` | Lists all available commands and basic instructions. |
| `/slp-ping` | Pings the bot to check its online status and responsiveness. |
| `/slp-catfac`| Generates and posts a randomized fact about felines. |
| `/slp-joke`   | Generates and posts a randomized joke. |
